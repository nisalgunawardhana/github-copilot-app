# Lesson 9 — Review and Next Steps

**Topic:** Summary
**Goal:** Automate recurring tasks and explore what's next

## Overview

This final lesson summarizes the learning journey from concept through merged features, covering repository connection, session management modes, custom instructions, testing with Playwright, collaborative canvas work, and automated merging.

## Automations

The lesson introduces **automations** for scheduling or on-demand agent work, recommending you start with read-only tasks like summarizing merged PRs or listing open backlog issues. Configuration options include:

- Manual triggers
- Scheduled execution
- Event-based activation (such as issue creation)

## Key Recommendations

- Invest in reusable infrastructure like instruction files and skills
- Match execution mode to task complexity:
  - **Plan** for strategy
  - **Interactive** for focused collaboration
  - **Autopilot** for isolated tasks
- Provide clear context about "what," "why," and "how" when directing the agent

## Additional Features

- Session chronicles

- Deep linking capabilities
